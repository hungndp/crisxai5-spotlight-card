A crisp vector spotlight card for [@crisxai5](https://x.com/crisxai5) — AI & crypto expert on X. A Node 22 program renders a phone-readable 1080×1350 SVG card (giant handle, hook line, four benefit rows, follow call-to-action) and copies `POST.json` to the output directory. The card introduces @crisxai5 as a must-follow for AI agents, crypto alpha, Web3 tooling and on-chain automation.

The X post that carries this card is the entry: its likes, reposts and quotes decide the places. The post text mentions @crisxai5 and one make.fun play code; its address goes in `POST.json` before submission.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/card.svg` (the spotlight card, 1080×1350) and `out/POST.json` (a copy of the entry's post link). No network, no clock, no files outside the repository — two runs write identical bytes.

## The card

- **Eyebrow:** SPOTLIGHT · ON X
- **Handle:** @crisxai5, with "AI & CRYPTO EXPERT" in gold
- **Hook:** "The feed where AI agents meet crypto alpha."
- **Four benefits:** AI Agents, Crypto Alpha, Web3 Tooling, On-chain Automation — each with a drawn vector glyph
- **Call to action:** FOLLOW @crisxai5 — x.com/crisxai5
